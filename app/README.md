# app

Модуль ParaBank поверх `core/`.

- `pages/`: static-классы страниц (элементы static arrow-поля, действия static-методы в `step()`).
- `components/`: повторяющиеся блоки (`LeftMenu`).
- `api/rest/`: один файл на эндпоинт (URL + вызов + типы), `builders/` собирают данные, `helpers/` вызывают, проверяют успех и возвращают JSON.
- `api/soap/`: envelope-шаблоны и вызовы SOAP-операций.
- `data/`: DDT-наборы и справочники, без локаторов и случайных данных.
